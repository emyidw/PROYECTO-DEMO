# Carpeta de Imágenes de Productos

## Instrucciones

Para agregar las imágenes de los productos, coloca 20 archivos PNG en esta carpeta con los siguientes nombres exactos:

```
producto1.png
producto2.png
...
producto20.png
```

## Especificaciones Recomendadas

- **Formato**: PNG o JPG
- **Dimensiones**: 300x300 px mínimo
- **Tamaño**: 200-300 KB máximo por imagen

## Notas

- Si las imágenes no existen, el sistema mostrará un placeholder
- La interfaz NO se romperá sin imágenes
- Puedes agregar imágenes en cualquier momento
